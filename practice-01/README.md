# Практическая работа №1

## Тема
Настройка окружения и первичный анализ данных.

## Вариант
Уровень B.

## Цель работы
Настроить рабочее окружение для машинного обучения, загрузить датасет и провести первичный анализ данных.

## Используемые технологии
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Этапы выполнения
1. Создание нового ноутбука в Google Colab.
2. Подключение необходимых библиотек.
3. Загрузка датасета.
4. Определение количества строк и столбцов.
5. Проверка типов данных.
6. Поиск пропущенных значений.
7. Расчёт базовых статистик.
8. Построение графиков.
9. Сохранение результатов.

## Результаты
В ходе работы освоены основные инструменты Google Colab и методы первичного анализа данных (EDA).

## Вывод
Практическая работа позволила изучить подготовку окружения, загрузку данных и способы их первоначального исследования. Полученные навыки будут использованы в последующих практических работах.
