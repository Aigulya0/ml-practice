# Практическая работа №2

## Тема
Полный исследовательский анализ данных (EDA).

## Вариант
Уровень B.

## Цель работы
Провести комплексный анализ датасета, исследовать числовые и категориальные признаки, выявить выбросы, корреляции и особенности распределения данных.

## Используемые технологии
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Этапы выполнения
1. Загрузка датасета.
2. Изучение структуры таблицы.
3. Классификация признаков по типам.
4. Анализ распределений числовых признаков.
5. Проверка выбросов.
6. Анализ категориальных признаков.
7. Построение корреляционной матрицы.
8. Исследование взаимосвязей признаков.
9. Анализ распределения целевой переменной.
10. Формулирование выводов.

## Методы анализа
- Описательная статистика
- Гистограммы
- Boxplot
- Countplot
- Корреляционная матрица
- Диаграммы рассеяния

## Результаты
Исследованы структура датасета, распределения признаков, возможные выбросы и корреляции между переменными.

## Вывод
Полный EDA позволяет лучше понять особенности данных до обучения модели машинного обучения. Анализ помогает обнаружить проблемы качества данных и определить направления дальнейшей предобработки.
