# Практическая работа №3

## Тема
Создание пайплайна предобработки данных.

## Вариант
Уровень B.

## Цель работы
Самостоятельно разработать пайплайн предобработки числовых и категориальных признаков с использованием ColumnTransformer и Pipeline.

## Используемые технологии
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn

## Этапы выполнения
1. Загрузка датасета.
2. Определение числовых и категориальных признаков.
3. Анализ пропущенных значений.
4. Выбор стратегий заполнения пропусков.
5. Масштабирование числовых признаков.
6. Кодирование категориальных признаков.
7. Создание ColumnTransformer.
8. Создание Pipeline.
9. Применение пайплайна к данным.
10. Проверка результата предобработки.

## Используемые методы
- SimpleImputer
- StandardScaler
- OneHotEncoder
- ColumnTransformer
- Pipeline

## Обоснование
Для числовых признаков может использоваться заполнение медианой, поскольку этот метод устойчив к выбросам.

Для категориальных признаков подходит заполнение наиболее частым значением.

StandardScaler применяется для масштабирования числовых признаков, а OneHotEncoder — для преобразования категорий в числовое представление.

## Вывод
В ходе работы изучены методы автоматизации предобработки данных. Использование Pipeline и ColumnTransformer позволяет создавать воспроизводимые процессы подготовки данных для машинного обучения.
