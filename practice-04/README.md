# Практическая работа №4

## Тема
Сравнение наборов признаков и выбор модели регрессии.

## Вариант
Уровень B.

## Цель работы
Сравнить несколько наборов признаков, исследовать мультиколлинеарность и выбрать оптимальную модель регрессии.

## Используемые технологии
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Этапы выполнения
1. Загрузка датасета.
2. Выделение числовых признаков.
3. Разделение данных на обучающую и тестовую выборки.
4. Обучение базовой модели Linear Regression.
5. Построение корреляционной матрицы.
6. Анализ мультиколлинеарности.
7. Удаление избыточных признаков.
8. Обучение модели на сокращённом наборе признаков.
9. Сравнение метрик моделей.
10. Построение графика остатков.
11. Обоснование финального выбора модели.

## Метрики оценки
- MAE — средняя абсолютная ошибка.
- MSE — средняя квадратичная ошибка.
- RMSE — корень из средней квадратичной ошибки.
- R² — коэффициент детерминации.

## Результаты
Проведено сравнение базовой и сокращённой моделей регрессии с использованием метрик качества.

## Вывод
Анализ корреляций и мультиколлинеарности помогает выявить избыточные признаки. Сравнение моделей позволяет оценить, как изменение набора признаков влияет на качество прогнозирования.

Финальный выбор модели должен основываться на результатах тестирования и анализе ошибок.
