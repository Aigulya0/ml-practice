# Практическая работа №6
## Предобработка и классификация текста с TF-IDF

**Вариант:** B (данные заданы)  
**Среда разработки:** Google Colab  
**Язык программирования:** Python

## Цель работы
Разработать пайплайн предобработки текстовых данных, включающий очистку текста, нормализацию, токенизацию, стемминг, TF-IDF векторизацию и обучение классификатора.

## Используемый датасет
**Название:** SMS Spam Collection

**Источник:** https://archive.ics.uci.edu/dataset/228/sms+spam+collection

Датасет содержит 5574 SMS-сообщения двух классов:
- `ham` — обычные сообщения.
- `spam` — нежелательные сообщения.

## Используемые библиотеки
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn

## Этапы выполнения работы

1. Загрузка датасета и изучение структуры данных.
2. Приведение текста к нижнему регистру.
3. Удаление пунктуации и цифр.
4. Удаление стоп-слов.
5. Токенизация текста.
6. Стемминг с использованием PorterStemmer.
7. Преобразование текста в числовые признаки с помощью TF-IDF.
8. Обучение модели Logistic Regression.
9. Оценка модели по метрикам Accuracy, Precision, Recall и F1-score.
10. Построение матрицы ошибок.
11. Анализ пяти ошибок классификации и формулирование гипотез об их причинах.

## Параметры TF-IDF

- `min_df = 2`
- `max_df = 0.95`
- `max_features = 5000`

## Результаты

Реализован пайплайн обработки текстовых данных с использованием TF-IDF и Logistic Regression.

Для оценки качества классификации используются Accuracy, Precision, Recall, F1-score и Confusion Matrix.

Проведён анализ неправильно классифицированных сообщений с целью выявления возможных причин ошибок модели.

## Вывод

В ходе практической работы №6 были изучены и применены основные методы обработки текстовых данных.

Реализована функция очистки текста, выполнены токенизация и стемминг. Для векторизации использован TF-IDF, после чего обучена модель Logistic Regression для классификации SMS-сообщений.

Практическая работа позволила изучить основные этапы построения модели классификации текста и методы оценки её качества.
