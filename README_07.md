# Практическая работа №7 — Random Forest

**Вариант B**

## Тема
Настройка гиперпараметров случайного леса и анализ важности признаков.

## Цель работы
Настроить гиперпараметры Random Forest, сравнить качество моделей и определить, какие признаки можно удалить без существенного снижения точности.

## Датасет
**Breast Cancer Wisconsin (Diagnostic)**

Источник: https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic

Датасет содержит 569 наблюдений, 30 числовых признаков и 2 класса.

## Используемые технологии
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Выполненные задания
1. Загружен и исследован датасет.
2. Обучена базовая модель Random Forest.
3. Выполнен подбор гиперпараметров `n_estimators`, `max_depth`, `min_samples_leaf` с помощью GridSearchCV.
4. Проведена кросс-валидация.
5. Выполнено сравнение базовой и настроенной моделей.
6. Построен график важности признаков.
7. Проведён эксперимент с удалением наименее важных признаков.
8. Выполнено сравнение качества полной и сокращённой моделей.

В ходе практической работы изучен алгоритм Random Forest, выполнена настройка гиперпараметров с помощью GridSearchCV и проведено сравнение моделей.

Эксперимент с удалением наименее важных признаков позволяет определить возможность упрощения модели без существенной потери качества.
